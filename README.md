# 🌌 Universe Physics Simulator

Интерактивная симуляция физики вселенной с ИИ-наблюдателем и алгоритмами прогнозирования.

![Preview](https://img.shields.io/badge/Version-2.0-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Возможности

### ⚛️ Физический движок
- Гравитационное взаимодействие частиц
- Сила Лоренца (магнитное поле)
- Броуновское движение (температура)
- Вязкость среды
- Законы сохранения энергии и импульса

### 🔮 Алгоритмы прогнозирования
- Линейная регрессия
- Экспоненциальное сглаживание
- Полиномиальная аппроксимация
- Разложение Фурье

### 🧠 ИИ Наблюдатель
- Анализ состояния системы в реальном времени
- Три режима голоса: нейтральный, научный, поэтический
- Комментарии физических процессов

### 🎮 Управление
- Параллакс-эффект мышью
- Настройка всех параметров в панели управления
- 5 слоёв с индивидуальными настройками

## 🚀 Деплой

### GitHub Pages (автоматически)
Репозиторий настроен для автоматического деплоя на GitHub Pages.

### Свой сервер
```bash
# Клонировать репозиторий
git clone https://github.com/smol0901-jpg/parallax-universe-physics.git

# Запустить (любой статический сервер)
cd parallax-universe-physics
python3 -m http.server 8000
# или
npx serve .
```

## 🎯 Использование

1. **Двигайте мышь** — управляйте параллаксом
2. **Нажмите ESC** — откройте панель управления
3. **Настройте физику** — гравитация, температура, вязкость
4. **Следите за ИИ** — он комментирует происходящее
5. **Смотрите прогнозы** — график предсказаний энергии

## 📊 Параметры физики

| Параметр | Описание | Диапазон |
|----------|----------|----------|
| G | Гравитационная постоянная | 0.1 - 5.0 |
| T | Температура системы | 0 - 1000 K |
| η | Вязкость среды | 0 - 0.5 |
| B | Магнитное поле | 0 - 2.0 |
